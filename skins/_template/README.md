# _template

Starter folder for a new skin.

1. Copy this folder to `skins/<site>/`, using the bare domain as the name.
2. Open `skin.css` and replace `<site>` in the guard with the real domain.
3. Add the rules.
4. Add the skin to the table in the top-level `README.md`.
5. Delete this `README.md` once the skin is real.
